## Deploy

1. Create a new GitHub repository and upload the **contents** of this ZIP at repository root, with index.html in the root.
2. Import the repository into Vercel using Other / static project settings. No build command or output directory required.
3. Assign the desired domain. If not `https://keepproof.vercel.app`, replace `https://keepproof.vercel.app` in all HTML, sitemap.xml, and robots.txt with the real domain (without trailing slash) and redeploy.
4. Test /guides/, /tools/, the three tools, /ads.txt and /sitemap.xml from an actual browser. Add the exact domain to Google Search Console and to the relevant AdSense account.
5. Check privacy and disclosure language again before turning on any new analytics, cookies, services or personalized ad formats.
