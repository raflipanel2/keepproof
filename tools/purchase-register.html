DATA STAYS IN THIS BROWSER

Private by design—with limits.

Saved entries use localStorage in this browser only. This is not encrypted secure storage, does not synchronize between devices, and can be lost if site data is cleared or the browser is reinstalled.

Do not enter payment-card numbers, passwords, account recovery codes or sensitive personal identifiers. Use ordinary document names or storage locations instead.

Export CSV periodically and keep it with your real receipts. The export is a plain-text file; store it appropriately. This tool does not upload documents.
