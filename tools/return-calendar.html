TOOL 01 / DEADLINE WORKSHEET

Return Window Calendar

Estimate a calendar date from a start date and policy duration. You must read the actual retailer policy to know which start date, exceptions and delivery requirements apply.

INPUT / POLICY FACTS

Calculate a date.

HOW TO USE THIS

Start with the written rule.

A retailer may begin counting from purchase, delivery, activation or receipt. Some policies use business days, an authorization deadline or the date goods must arrive back. This tool only adds calendar days.

Example: if the start date is 11 November and the next day is day 1, a 30-calendar-day period points to 11 December. If the start counts as day 1, it points to 10 December. This difference is why the policy wording matters.

Do not assume a holiday or weekend automatically extends a deadline. Build a time buffer for shipping and authorization.
